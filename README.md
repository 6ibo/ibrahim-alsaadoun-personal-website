# إبراهيم سعدون · Ibrahim Alsaadoun

A bilingual personal website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide. It exports static files for free GitHub Pages hosting. Ibrahim's channel mark, portrait collection, football covers and videos, and his supplied social links are included.

## Edit the content

Most content lives in [`src/data/content.ts`](src/data/content.ts):

- Update the English and Arabic copy in `copy`.
- Replace `public/images/channel-logo.jpg` to change the channel logo used in the hero and navigation. Its outer black corners are cropped away in the UI.
- Replace `public/images/gallery/portrait-green-cutout.png` to change the About portrait. Gallery photos are listed in `photos`; add image files in `public/images/gallery/` and entries there to expand the gallery. Gallery cards share a 4:5 frame and a warm neutral surface.
- Add projects to `projects` with a unique `slug`, translated `title` and `description`, technology list, cover image, optional gallery paths, and optional public URL. The build creates one static details page per project.
- The two local videos live in `public/videos/`; replace those files to keep their current entries, or add files and entries in `videos`. Videos load only when a visitor presses play.
- Update social destinations in `socialLinks`. Empty links are rendered as disabled placeholders. The current YouTube, Instagram, TikTok, and GitHub URLs were supplied by Ibrahim.

Use compressed WebP or AVIF photos. The Arabic font is IBM Plex Sans Arabic, an open source alternative; no Thmanyah font files are bundled.

## Run locally

```sh
npm ci
npm run dev
```

Checks:

```sh
npm run lint
npm run typecheck
npm run build
```

The static export is written to `out/`.

## Private hosting

The site is being deployed as a private Sites website, with owner-only access. Its platform URL is generated by Sites; this is not a separately registered custom domain. GitHub Pages on the free personal plan is not used because it publishes the site publicly. Future content updates can be made in Codex and republished to the existing private Site.
