# Ibrahim Alsaadoun Personal Website

This is a private backup repository for the bilingual personal website.

## Complete source backup

Download the latest source archive from the repository’s **Releases** page and extract it. The archive includes the Next.js source, configuration, personal images, and the two local video files. Generated folders such as `node_modules`, `.next`, and `out` are excluded; regenerate them with `npm ci` and `npm run build`.

## Run locally

```sh
npm ci
npm run dev
```

Most content and profile links can be edited in `src/data/content.ts`.
